# Multi-Platform Product Price Comparison and Purchase Recommendation System

## Project Description

This project compares product prices across Amazon, Flipkart, and Croma.

The system works with home appliances and electronics such as:

- Refrigerators
- Washing Machines
- Air Conditioners
- Microwave Ovens
- Televisions
- Laptops
- Air Coolers

The system also uses historical price data and machine learning to predict an estimated price.
